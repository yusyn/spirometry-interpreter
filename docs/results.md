# نتایج ارزیابی مدل و سیستم هیبریدی

این سند برای گزارش پروژه لیسانس آماده شده و خلاصه وضعیت فعلی هسته تفسیر است.

## داده

- منبع: Refined NHANES 2007–2012 (Mendeley Data)
- پس از پاک‌سازی: ۱۶٬۵۹۶ نمونه
- برچسب هدف (`pattern`): Normal / Obstructive / Restrictive / Mixed
- تقسیم Train/Test: ۸۰/۲۰ با `stratify` و `random_state=42`

توزیع تقریبی کلاس‌ها (کل داده):

| الگو | تعداد تقریبی |
|------|----------------|
| Normal | ۱۵٬۰۷۰ |
| Obstructive | ۷۴۴ |
| Restrictive | ۷۱۷ |
| Mixed | ۶۵ |

## مدل‌های یادگیری ماشین

| مدل | Macro F1 (تست) | توضیح |
|-----|----------------|--------|
| Random Forest | ≈ 0.78 | مدل پایه |
| **XGBoost** | **≈ 0.83** | مدل نهایی انتخاب‌شده |

جزئیات XGBoost روی مجموعه تست (۳۳۲۰ نمونه):

| کلاس | Precision | Recall | F1 |
|------|-----------|--------|-----|
| Mixed | 0.69 | 0.69 | 0.69 |
| Normal | 0.99 | 0.97 | 0.98 |
| Obstructive | 0.89 | 0.97 | 0.93 |
| Restrictive | 0.62 | 0.89 | 0.73 |

- Accuracy کلی ≈ 96%
- مدیریت نامتوازنی: SMOTE روی داده آموزش + ارزیابی با Macro F1

## سیستم قاعده‌محور

نسخه فعلی (v3):

- معیار انسداد: GOLD fixed ratio (`FEV1/FVC < 0.70`)
- `%predicted` تقریبی با معادلات ECSC/Quanjer 1993
- شدت انسداد بر اساس GOLD و `FEV1 %predicted`
- نقش: **لایه مکمل بالینی** (نه تصمیم‌گیرنده نهایی)

ارزیابی Rule به‌تنهایی روی همان تست:

- Macro F1 ≈ **0.39**
- علت ضعف اصلی: نبود LLN دقیق و محدودیت فرمول‌های تقریبی نسبت به برچسب‌های دیتاست

## سیستم هیبریدی

تعریف نقش‌ها:

- تصمیم نهایی الگو: مدل XGBoost
- Rule: گزارش GOLD + %predicted + شدت
- در صورت اختلاف: پرچم «نیاز به بررسی پزشک»

یافته ارزیابی توافق:

- نرخ توافق Rule و ML ≈ 66%
- در موارد اختلاف، مدل معمولاً به برچسب واقعی نزدیک‌تر بود

نتیجه: هیبریدی فعلی از نظر دقت برابر مدل است، ولی از نظر **شفافیت بالینی و هشدار اختلاف** ارزش افزوده دارد.

## تفسیرپذیری (SHAP)

- اهمیت کلی ویژگی‌ها: نسبت `FEV1/FVC`، سپس `FVC`، `Age`، `FEV1`
- در وب‌اپ: برای هر پیش‌بینی، ۵ ویژگی مؤثر با مقدار SHAP نمایش داده می‌شود

## محدودیت‌ها

1. کلاس Mixed نمونه کمی دارد و F1 آن پایین‌تر است.
2. معادلات ECSC تقریبی‌اند و جایگزین GLI کامل نیستند.
3. تشخیص Restrictive بدون TLC قطعی نیست.
4. OCR هنوز پیاده‌سازی نشده است.
